# Де дешевше? — Telegram Mini App

Порівняння цін у Сільпо, АТБ, Варус, Новус, Траш і Велмарт.

## Структура

- `app.py` — веб-сервер Mini App та HTML-інтерфейс (вкладки «Пошук» / «Акції» / «Відгук» унизу, поле адреси й кнопка гео).
- `price_finder.py` — парсери магазинів, кеш, сортування, категорії акцій, пошук найближчих магазинів Сільпо, АТБ, Варуса й Новуса.
- `bot.py` — запуск бота, читання змінних оточення, токена й URL.
- `bot_handlers.py` — команди бота, кнопка відгуку та адмінська статистика.
- `stats_store.py` — облік користувачів і збереження відгуків у `stats.json`.
- `assets/start.png` — зображення для `/start`.
- `render.yaml` — готовий Blueprint для Render (web + worker).

## Локальний запуск

```bat
pip install -r requirements.txt
python tunnel.py
python app.py
python bot.py
```

Локально бот візьме HTTPS-посилання з `tunnel_url.txt` (якщо немає `WEBAPP_URL`).
Токен можна задати двома способами:

1. змінна оточення `BOT_TOKEN`;
2. файл `bot_token.txt` у папці проєкту (уже в `.gitignore`).

Файли `tunnel_url.txt`, `webapp_url.txt`, `bot_token.txt` і `stats.json` до репозиторію не потраплять.

Змінні оточення:

| Змінна | Де потрібна | Що це |
|---|---|---|
| `BOT_TOKEN` | бот | токен від @BotFather (обов'язково) |
| `WEBAPP_URL` | бот | HTTPS-посилання на веб-сервіс (на Render підставляється автоматично) |
| `ADMIN_IDS` | бот | Telegram ID адміністраторів через кому — доступ до `/stats`, `/feedbacks` і відгуків; ID `1591310608` уже в коді |
| `STATS_FILE` | бот | шлях до файлу статистики (типово `stats.json` поруч із кодом) |
| `PORT` | web | Render задає автоматично, `app.py` читає його |

Приклад локально (PowerShell):

```powershell
$env:WEBAPP_URL="https://ваш-домен.lhr.life"
$env:ADMIN_IDS="123456789"
python bot.py
```

…або просто створіть `bot_token.txt` із токеном і запускайте `python bot.py`.

Дізнатися свій Telegram ID можна, наприклад, у боті @userinfobot.

## Статистика користувачів (адмін-функція)

Бот автоматично враховує кожного користувача, який написав йому (`/start`,
«Інформація», «Відкрити», відгук або дані з Mini App). У `stats.json` зберігаються:

- кількість унікальних користувачів, нових за 24 год / 7 днів, активних за 24 год;
- кількість запусків `/start`, відкриттів Mini App і відгуків;
- профіль кожного користувача (ID, username, час першого й останнього звернення, лічильники дій, координати й адреса);
- самі відгуки з категорією, текстом і часом.

Команди для адміністраторів (ID з `ADMIN_IDS`; `1591310608` додано за замовчуванням):

- `/stats` — короткий звіт і останні користувачі;
- `/feedbacks` — 10 останніх відгуків, кнопки «⬅️ Новіші» / «Старіші ➡️» листують назад. Також можна `/feedbacks 2`;
- `/seturl <https://...>` — змінити посилання на Mini App;
- `/reseturl` — скасувати `/seturl` і повернутися до `WEBAPP_URL`.

### Що робить `/seturl`

`/seturl https://...` зберігає HTTPS-адресу у файл `webapp_url.txt`. Цей файл має **найвищий пріоритет**: бот використовує його замість змінної `WEBAPP_URL` і `tunnel_url.txt`, поки не виконано `/reseturl`. Після `/seturl` бот одразу присилає кнопку з новою адресою, тому перезапускати його не потрібно.

На безплатному плані Render файл існує до перезапуску worker'а — для постійної зміни оновіть `WEBAPP_URL` у налаштуваннях сервісу. Команда доступна адміністраторам.

> **Важливо:** на безплатному плані Render файлова система тимчасова — після
> перезапуску worker'а `stats.json` очищується. Для постійної статистики
> підключіть SQLite/PostgreSQL або будь-який зовнішній сховищний сервіс.

## Відгуки

Надіслати ідею або повідомити про несправність можна двома способами:

- кнопка «💬 Відгук» у клавіатурі бота, інлайн-кнопка під `/start` або команда `/feedback` —
  бот попросить написати текст і перешле його адміністраторам;
- вкладка «💬 Відгук» у Mini App — виберіть тип («Ідея», «Несправність», «Інше»),
  напишіть текст і натисніть «Надіслати». Повідомлення прийде в бот через
  `Telegram.WebApp.sendData()` і також потрапить адміністраторам.

Якщо `ADMIN_IDS` не задано, відгуки все одно зберігаються у `stats.json` —
їх можна переглянути командою `/feedbacks` після налаштування адміністраторів.

## Адреса, геолокація й знижки

- У Mini App у вкладках «Пошук» і «Акції» є поле адреси та кнопка «Моє місце»
  (`Telegram.WebApp.LocationManager`). Адресу можна ввести текстом, наприклад
  «Київ, вул. Хрещатик» — за збігом вулиці/району визначаються координати, а далі
  вибираються найближчі магазини всіх чотирьох основних мереж. Якщо збігу немає,
  використовується центр Києва.
- У боті є кнопка «📍 Моє місце» (`request_location=True`). Гео зберігається у
  `stats.json`, і бот одразу показує обрані магазини з відстанню.
- **Сільпо**: список відділень із координатами
  (`https://sf-ecom-api.silpo.ua/v1/uk/branches`); асортимент і ціни беруться
  з трьох найближчих відділень із онлайн-каталогом (`hasPickup`).
- **АТБ**: сайт шукає магазини через `/site/getstoresgeo` за координатами;
  `id` найближчого магазина передається в пошук Multisearch як `location`.
  Саме тому ціни залежать від обраної точки.
- **Варус**: список магазинів із координатами береться з Elasticsearch сайту;
  `id` найближчого передається в GraphQL як `shopId` (впливає на ціну та наявність).
- **Новус**: API `POST /api/popup/shops` повертає магазини з координатами;
  найближчий вибирається через cookie `novus_shop` (як на сайті). У межах
  ~60 км від Києва запитуємо тільки київські магазини, щоб перший пошук був
  швидшим; для інших міст — усі доступні міста.
- **Траш і Велмарт**: публічні API не дають вибрати конкретну точку,
  тому використовуються ціни сайту без прив'язки до магазину.
- Усі доступні ціни й акції — з онлайн-каталогів. Тому бейдж на картці має вигляд
  «знижка онлайн». Надійних даних про поличні (офлайн) акції ці API не дають:
  у самому магазині знижка може відрізнятися.

## Деплой на Render

1. Залийте репозиторій на GitHub.
2. Render → **New → Blueprint** → виберіть репозиторій.
3. Під час створення Blueprint вкажіть `BOT_TOKEN` і `ADMIN_IDS` вручну.
4. `WEBAPP_URL` підставиться автоматично з веб-сервісу через `fromService`.

Створяться два сервіси:

- `gde-deeshevle-web` — Mini App і API;
- `gde-deeshevle-bot` — бот із кнопками «Відкрити», «Відгук», «Інформація», «📍 Моє місце» та статистикою.

### Важливо

- Токен бота **більше не зашитий у коді**. Якщо він уже потрапив до GitHub,
  відкликайте його в @BotFather і створіть новий.
- На безплатному плані Render веб-сервіс засипляє — перший запит після простою
  може бути повільним.
- Кеш цін живе в пам'яті процесу 5 хвилин; після перезапуску сервісу він очищується.
- Ключі `ATB_MS_*` / `VARUS_MS_*` у `price_finder.py` — публічні ключі frontend API
  магазинів, не токени бота.
