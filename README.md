# Де дешевше? — Telegram Mini App

Порівняння цін у Сільпо, АТБ, Варус, Новус, Траш і Велмарт.

## Структура

- `app.py` — веб-сервер Mini App та HTML-інтерфейс (вкладки «Пошук» / «Акції» / «Відгук» унизу).
- `price_finder.py` — парсери магазинів, кеш, сортування, категорії акцій.
- `bot.py` — запуск бота, читання змінних оточення, токена й URL.
- `bot_handlers.py` — команди бота, кнопка відгуку та адмінська статистика.
- `stats_store.py` — облік користувачів і збереження відгуків у `stats.json`.
- `assets/start.png` — зображення для `/start`.
- `render.yaml` — готовий Blueprint для Render (web + worker).

## Локальний запуск

```bat
pip install -r requirements.txt
python tunnel.py
python app.py
python bot.py
```

Локально бот візьме HTTPS-посилання з `tunnel_url.txt` (якщо немає `WEBAPP_URL`).
Токен можна задати двома способами:

1. змінна оточення `BOT_TOKEN`;
2. файл `bot_token.txt` у папці проєкту (уже в `.gitignore`).

Файли `tunnel_url.txt`, `bot_token.txt` і `stats.json` до репозиторію не потраплять.

Змінні оточення:

| Змінна | Де потрібна | Що це |
|---|---|---|
| `BOT_TOKEN` | бот | токен від @BotFather (обов'язково) |
| `WEBAPP_URL` | бот | HTTPS-посилання на веб-сервіс (на Render підставляється автоматично) |
| `ADMIN_IDS` | бот | Telegram ID адміністраторів через кому — доступ до `/stats`, `/feedbacks` і відгуків |
| `STATS_FILE` | бот | шлях до файлу статистики (типово `stats.json` поруч із кодом) |
| `PORT` | web | Render задає автоматично, `app.py` читає його |

Приклад локально (PowerShell):

```powershell
$env:WEBAPP_URL="https://ваш-домен.lhr.life"
$env:ADMIN_IDS="123456789"
python bot.py
```

…або просто створіть `bot_token.txt` із токеном і запускайте `python bot.py`.

Дізнатися свій Telegram ID можна, наприклад, у боті @userinfobot.

## Статистика користувачів (адмін-функція)

Бот автоматично враховує кожного користувача, який написав йому (`/start`,
«Інформація», «Відкрити», відгук або дані з Mini App). У `stats.json` зберігаються:

- кількість унікальних користувачів, нових за 24 год / 7 днів, активних за 24 год;
- кількість запусків `/start`, відкриттів Mini App і відгуків;
- профіль кожного користувача (ID, username, час першого й останнього звернення, лічильники дій);
- самі відгуки з категорією, текстом і часом.

Команди для адміністраторів (ID з `ADMIN_IDS`):

- `/stats` — короткий звіт і останні користувачі;
- `/feedbacks` — останні 5 відгуків;
- `/seturl <https://...>` — змінити посилання на Mini App (без `ADMIN_IDS` команда доступна всім, для локальної розробки).

> **Важливо:** на безплатному плані Render файлова система тимчасова — після
> перезапуску worker'а `stats.json` очищується. Для постійної статистики
> підключіть SQLite/PostgreSQL або будь-який зовнішній сховищний сервіс.

## Відгуки

Надіслати ідею або повідомити про несправність можна двома способами:

- кнопка «💬 Відгук» у клавіатурі бота, інлайн-кнопка під `/start` або команда `/feedback` —
  бот попросить написати текст і перешле його адміністраторам;
- вкладка «💬 Відгук» у Mini App — виберіть тип («Ідея», «Несправність», «Інше»),
  напишіть текст і натисніть «Надіслати». Повідомлення прийде в бот через
  `Telegram.WebApp.sendData()` і також потрапить адміністраторам.

Якщо `ADMIN_IDS` не задано, відгуки все одно зберігаються у `stats.json` —
їх можна переглянути командою `/feedbacks` після налаштування адміністраторів.

## Деплой на Render

1. Залийте репозиторій на GitHub.
2. Render → **New → Blueprint** → виберіть репозиторій.
3. Під час створення Blueprint вкажіть `BOT_TOKEN` і `ADMIN_IDS` вручну.
4. `WEBAPP_URL` підставиться автоматично з веб-сервісу через `fromService`.

Створяться два сервіси:

- `gde-deeshevle-web` — Mini App і API;
- `gde-deeshevle-bot` — бот із кнопкою «Відкрити», «Відгук», «Інформація» та статистикою.

### Важливо

- Токен бота **більше не зашитий у коді**. Якщо він уже потрапив до GitHub,
  відкликайте його в @BotFather і створіть новий.
- На безплатному плані Render веб-сервіс засипляє — перший запит після простою
  може бути повільним.
- Кеш цін живе в пам'яті процесу 5 хвилин; після перезапуску сервісу він очищується.
- Ключі `ATB_MS_*` / `VARUS_MS_*` у `price_finder.py` — публічні ключі frontend API
  магазинів, не токени бота.
